# nopCommerce QA Testing Project

## Project Overview
Hands-on QA testing portfolio project for the nopCommerce demo e-commerce application.

**Application:** https://demo.nopcommerce.com/  
**Project Type:** Manual Web Application Testing  
**Testing Focus:** Functional, Smoke, Regression, Exploratory, Negative, Validation, Integration and System Testing.

> This repository contains QA artifacts prepared for hands-on testing practice.

## Application Scope
The demo store provides customer-facing e-commerce functionality including registration/login, product search, categories, product browsing, wishlist, shopping cart and checkout-related workflows.

The official nopCommerce demo is reset periodically, so test evidence should include the execution date/time and application state observed during testing.

## Repository Structure
- `Test-Plan/` — test approach, scope, risks and entry/exit criteria
- `Test-Cases/` — functional and negative test cases
- `Bug-Reports/` — verified defects only
- `Test-Execution/` — execution results and metrics
- `RTM/` — requirement-to-test-case mapping
- `Test-Summary/` — final test summary
- `Screenshots/` — evidence captured during execution
- `Postman/` — API artifacts, if API testing is actually performed

## Execution Rules
- Do not mark a test as Pass/Fail until it has been executed.
- Do not add a defect unless it has been reproduced and supported with evidence.
- Record browser, OS, date/time and environment for defects.
- Never publish passwords, tokens, personal information or other secrets.
